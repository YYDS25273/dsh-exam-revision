# 复习题截图 → 详解 Word

一套可复用的流水线：**读图 → 解题 → 建题库 → 排版 → 交付**。
排版由 `exam_docx` 工具完成（本技能所在插件的工具），你只负责把题目读准、解对、讲透。

## 什么时候用

- 用户发来一张或多张题目截图/照片，说"转成 Word""做一下""写解析""整理复习"；
- 用户说"继续加""下一章""还有几张图"——沿用同一份题库文件增量追加；
- 用户要求"答案速查""知识点归纳"——这本来就是产出的固定部分。

## 第一步：读图（最重要，错了后面全错）

1. **逐张读完再动手**。不要看一张写一张，先把这批图全部过一遍，避免编号错乱、漏题。
2. 逐题抄录：**题号、题型、题干、全部选项（A/B/C/D 一个不漏）、公式与数字**。
3. 题型从截图的分节标题判断，常见对应关系：

   | 截图里的标题 | kind | 说明 |
   |---|---|---|
   | 单选题（共 N 题，M 分） | `single` | 四个选项，答案一个字母 |
   | 多选题 | `multi` | 答案多个字母，如 `ABD` |
   | 判断题 | `judge` | options 固定 `{"A":"对","B":"错"}` |
   | 填空题 | `blank` | 题干含 `______`，答案填文字/数字 |
   | 简答题 | `short` | 无选项，答案是结论句 + 答题要点 |

4. 截图模糊、选项被切掉、题干有遮挡时，**不要猜**。在解析里明确写"截图此处不清，按 XXX 理解"，或直接问用户。宁可标注，不要编造选项。
5. 公式按下面的「数学写法」转录，不要丢掉上下标（`I_set^Ⅱ`、`K_sen` 这类）。

## 第二步：解题（教材级详解，不是只给答案）

每道题都要回答三件事，缺一不可：

- **答案**：确定就直说；有争议的把主流口径放答案、把另一种说法写进易错。
- **为什么**：分步推导，每一步写清依据（公式来源、整定原则、定义原文）。
- **考什么**：这道题在教材里的位置、同一考点还会怎么变着问。

推荐的解析结构（`steps` 数组，通常 4～6 段）：

```
第一段：抓住定义 / 先立判据（把解题的"钥匙"点出来）
中间段：分步推导或逐项排除（每段一个点，首句加粗当小标题）
倒数段：结论句（所以选 X）
末段（可选）：延伸——这个结论在别的题里怎么用
```

各题型的侧重：

- **单选**：逐项排除是主体，**每个错误选项都要说明错在哪**，不能只说"对的是 D"。
- **多选**：逐项判对错，并指出哪些选项容易被漏选/多选。
- **判断**：先给判断依据（一句话说清对在哪、错在哪），再点出命题人改动了哪个字。
- **填空**：答案 + 为什么是它（推导或定义），计算类要写算式。
- **简答**：按"一、二、三"分点，每点一句话打头再展开；先给一句结论式【答案】再展开要点。

`points`（考点）3～5 条，写"教材里的位置 + 判断标准 + 关联题号"。
`traps`（易错）2～3 条，写命题人怎么设坑、考场上怎么躲。

## 第三步：建题库 JSON

**题库文件是唯一数据源**，Word 是它的渲染结果。以后追加章节只改 JSON 再重渲染，不要手工改 docx。

结构：

```json
{
  "cover": {"text1": "继电保护", "text2": "复 习 题 详 解",
            "subtitle": "逐题详解　·　分步推导　·　考点归纳　·　易错提醒"},
  "chapters": [
    {
      "title": "第一章　概述",
      "meta": "本章共 100 题、满分 100 分；其中单选题 40 题（每题 1 分）",
      "sections": [
        {
          "title": "一、单选题（共 40 题，40 分）",
          "questions": [
            {
              "id": 1,
              "kind": "single",
              "stem": "远后备保护通常安装在（　　）。",
              "options": {"A": "…", "B": "…", "C": "…", "D": "…"},
              "answer": "D",
              "steps": ["**抓住定义**：…", "…"],
              "points": ["…"],
              "traps": ["…"]
            }
          ]
        }
      ]
    }
  ]
}
```

字段约定：

- `id` 在**本章本节内**从 1 连续编号，与截图题号一致；重排时整段改号，别留空号。
- `kind` 省略时按 `single` 处理。
- `single` / `multi` / `judge` 必须有 `options`；`blank` / `short` 不要给 `options`。
- `answer`：单选 `"D"`；多选 `"ABD"`；判断 `"A"`（对）或 `"B"`（错）；填空/简答写文字。
- `steps` 必填且非空；`points` / `traps` 可省，但省了就少了两个板块，尽量别省。
- 判断题的 `options` 固定写 `{"A": "对", "B": "错"}`。

## 第四步：排版

**首选**：调用插件工具 `exam_docx`。

```
exam_docx(questions = "D:\\复习\\继电保护\\题库.json",   // 也可直接传 JSON 文本
          out        = "D:\\复习\\继电保护\\继电保护复习题详解.docx")
```

返回 `{ok, path, chapters, questions, log}`。失败时错误信息会带 python 的末尾几行堆栈，按提示修 JSON 再调一次即可。

**大题库一律传文件路径**，不要把几十万字符的 JSON 塞进参数。

**兜底**（工具不可用时，本技能是自包含的）：直接跑脚本。

```powershell
# 本技能目录 /assets/build_docx.py，依赖 python-docx
& "<python>" "<本技能目录>\assets\build_docx.py" "<题库.json>" "<输出.docx>"
```

python 用 DSH 自带运行时：
`%USERPROFILE%\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe`
脚本与工具走的是同一份代码，产出完全一致。

## 第五步：验收与交付

1. 用 `present` 把 docx 交给用户（Office 文档必须走 present，不要只在正文里写路径）。
2. 报告：本章题数、累计题数、页数、本批**最容易错的 3～5 个点**（从 traps 里挑）。
3. 顺带列出本批答案速览表（选择/判断用表格，简答给一句话结论），方便手机上对答案。

## 数学写法

公式用 `$...$` 包起来，渲染成 Word 原生公式（可选中、可编辑）。支持的写法：

| 写法 | 效果 | 说明 |
|---|---|---|
| `$I_{set}^{II}$` | I 上标 II 下标 set | 大括号包住多字符 |
| `$\frac{K_{rel}K_{ss}}{K_{re}}$` | 真分数 | 只支持 `\frac` |
| `$\Delta t$`、`$\Sigma$` | Δt、Σ | 常用希腊字母 |
| `$\ge$`、`$\le$`、`$\times$`、`$\approx$`、`$\sim$` | ≥ ≤ × ≈ ～ | 符号表 |
| `$\sqrt{3}$` | √3 | 可用，但个别渲染器会有小瑕疵 |

**注意**：

- 单字符下标直接写 `$I_A$`；多字符必须用大括号 `$I_{BC}$`。
- **不要用** `\text{}`、`\dot{}`、`\bar{}`——解析器不支持，会原样打出 "text"/"dot"。
  相量就写 `$U_a+U_b+U_c=3U_0$`，再用文字说明"各量均为相量"。
- 根号若在正文里显得突兀，用普通字符 `√3`，别硬套 `\sqrt`。
- 中文、标点不要放进 `$...$` 里。

## 排版已经定死的规则（不用你操心，但别去改）

- 五个板块五色分区：**题目蓝、答案绿、解析青、考点紫、易错橙**。
  答案用绿色而非红色——红色在中文语境是批改色，容易被读成"错误答案"。
- 题干 + 选项 + 答案**不跨页拆散**，一题一张卡片。
- 每章自动分页，章标题带下划线，题型标题带浅蓝底纹条。
- 文末自动生成「附录　答案速查表」（选择题 5 组一行，简答挂一句话结论）。
- 封面、目录（打开文档时自动更新）自动生成。

## 已知的坑

1. **Word 打开大文档很慢**：100 页以上、几百个公式的 docx，Word 首次打开要十几秒（还要更新目录域）。
   **不要因为"没反应"就杀 Word 进程**——强杀会让 Word 进入安全模式，甚至把该文件加入
   `Resiliency\DisabledItems` 黑名单，之后再也打不开。
   症状与解法：文件打不开且标题栏显示"安全模式"→ 查
   `HKCU\Software\Microsoft\Office\16.0\Word\Resiliency\DisabledItems`，删掉对应值即可。
2. **增量追加**：新图进来时，先读现有 `题库.json`，追加 chapter/section，保持 id 连续，再整体重渲染。
   不要新建第二个 docx——用户要的是"一本册子"。
3. **页数会随题量涨**：每章排完大致 1～1.5 页/题（含五色板块），报页数时用渲染结果，别估。
4. **别把答案抄错位**：多选题答案字母顺序按 A→B→C→D 排列；判断题用"A/B"而不是"对/错"当 answer。

## 最小工作示例

用户发来 3 张图，说"帮我做成复习资料"：

1. 读完 3 张图 → 确认是「第二章 电网的电流保护」单选 1～21 题；
2. 逐题解题，写 steps/points/traps；
3. 写 `题库.json`（若已有则追加）；
4. `exam_docx(questions="…\\题库.json", out="…\\继电保护复习题详解.docx")`；
5. `present` 文档 + 给答案速览表 + 点出 3 个易错点。
